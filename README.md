The GPS's one-line excuse for sending the driver down the wrong road, for the [The GPS Swears It Was a Shortcut](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9) bounty on make.fun: a single line of plain text in the GPS's own voice, smug and defensive, blaming the map for a dirt track it listed as a scenic route, with one concrete detail and a twist at the end — the GPS doubles down instead of apologising.

`main.py` writes the excuse to `/output/entry.txt` (UTF-8, 157 bytes, one line) and self-checks the gate before writing: 1–200 characters, a single line, not only white space. The program is deterministic — repeated runs produce byte-identical output.

## Run

```sh
python3 main.py
```
